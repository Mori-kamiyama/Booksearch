# OCR精度分布の二極化分析レポート

## 概要

複数のOCRメソッド（Gemini、Qwen、Claude、Llama、AmazonNova）で本棚画像から16冊の書籍タイトルを認識させ、OCR精度の分布パターンを分析しました。

結果として、**OCRメソッドごとに異なる二極化パターン**が確認されました。

---

## 主な発見

### ✅ 二極化が明確に存在するモデル

#### 1. **AmazonNovaLite** （最強の二極化）
- **二極化スコア: 0.750** ← 強く二極化
- **完全認識（≥90%）:** 6/16冊 (37.5%)
- **不完全（<90%）:** 10/16冊 (62.5%)
- **ギャップ:** 0.766 （非常に大きい）

**特徴:**
```
完全認識グループ（1.0） ────────────────────> ギャップ 0.766 ────────────────> 失敗グループ（0.07-0.26）
```

- 「できる本」は ほぼ完全に認識（スコア 1.0）
- 「できない本」は ほぼ全く認識できない（スコア 0.07-0.26）
- **結論: 本によって認識可能性が完全に分かれている**

#### 2. **Gemini** （強めの二極化）
- **二極化スコア: 0.592**
- **完全認識:** 5/16冊 (31%)
- **不完全:** 11/16冊 (69%)
- **ギャップ:** 0.473

**特徴:**
- AmazonNova と同様に、完全認識と失敗が分かれている
- ただし、ギャップは AmazonNova より小さい
- 不完全群の内部にはバリエーション（0.2-0.5）がある

---

### ⚠️ 二極化が弱いモデル

#### 3. **Qwen2.5-VL-3B** （中程度の二極化）
- **二極化スコア: 0.331**
- **完全認識:** 4/16冊 (25%)
- **不完全:** 12/16冊 (75%)
- **ギャップ:** 0.331 （中程度）

**特徴:**
```
完全認識（1.0） ──────> 中程度グループ（0.54-0.86） ──────> 失敗グループ
```

- スコア分布が 0.5-0.9 の範囲に集中
- 「完全」と「失敗」の中間に多くの本が分布
- **結論: スコアが均等に分布、二極化が弱い**

#### 4. **Llama3.2V** （わずかな二極化）
- **二極化スコア: 0.299**
- **完全認識:** 3/16冊 (19%)
- **不完全:** 13/16冊 (81%)
- **ギャップ:** 0.398

#### 5. **Claude3Haiku** （二極化なし）
- **二極化スコア: 0.000**
- **完全認識:** 0/16冊 (0%)
- **全て不完全:** 16/16冊 (100%)

**特徴:**
- 全ての書籍が不完全認識
- 二極化なし（グループ分けできない）

## 二極化の原因分析

### AmazonNova が強く二極化する理由

1. **完全認識グループ（スコア 1.0）:**
   - 会社というモンスターが私たちを不幸にしているのかもしれない。
   - 経営も人生も「ひねらんかい」
   - 校則が変わる、生徒が変わる。学校が変わる。
   - 幸せをつくるシゴト
   - 旅をする木
   - そらみみ植物園
   
   → **特徴**: 文字が大きく、背景がシンプル、または一般的な書籍

2. **失敗グループ（スコア < 0.3）:**
   - ビジネスの未来　山口周
   - ファイブ・フェイ・ポジショニング戦略
   - プラントハンター西畠清順
   - など
   
   → **特徴**: 特殊な書体、複雑な背景、またはOCRが苦手な漢字配列

### Qwen が二極化しない理由

- **スコア分布が 0.54-0.86 に集中**
  - 多くの書籍が「中程度に認識」される
  - 完全失敗する書籍が少ない
  - 「まあまあ読める」というレベルで統一

- **標準偏差が最も小さい (0.173)**
  - スコアのばらつきが小さい
  - 本によって精度がほぼ同じ

## 実務的な意味

### オンライン棚システムへの影響

1. **AmazonNova + Gemini のような二極化するモデル:**
   - ✅ **メリット**: 完全認識できた本は信頼度が高い
   - ❌ **デメリット**: 失敗した本を自動的に除外すると、正解率が下がる
   - 📋 **対策**: 確度の高い結果をフィルタリング、低確度は人間レビュー

2. **Qwen のような均等分布するモデル:**
   - ✅ **メリット**: 全ての本についてそこそこの結果が得られる
   - ❌ **デメリット**: 「本当に正しいのか？」という判定が難しい
   - 📋 **対策**: 複数モデルの結果を統合する、閾値設定を工夫する

3. **Claude のような全失敗するモデル:**
   - ❌ **この画像/タスクには不向き**

## 推奨事項

### 1. モデル選択
- **優先順位: AmazonNova > Gemini > Qwen**
  - AmazonNova は高精度で二極化が明確（信頼度が高い）
  - Gemini は次点
  - Qwen は精度が均等（フォールバック用）

### 2. アンサンブル戦略
```
IF (AmazonNova スコア >= 0.9):
    → 結果を採用（高信頼度）
ELSE IF (Gemini スコア >= 0.8 AND Qwen スコア >= 0.7):
    → 複数モデルで確認済み
ELSE:
    → 人間レビュー必要
```

### 3. ユーザー向けUI
- **✅ 完全認識**: 自動的に棚に追加
- **⚠️ 部分認識**: 「確認してください」と表示
- **❌ 失敗**: 「再度撮影してください」と提案

実行方法:

```bash
  outputs/add_tag_claude/summary.json \
  outputs/add_tag_llama/summary.json \
  outputs/add_tag_nova/summary.json

# 単一モデルの詳細分析
uv run python scripts/analyze_ocr_polarization.py \
  --single outputs/add_tag_nova/summary.json
```

### 二極化スコアの計算式

```python
if perfect > 0 and imperfect > 0:
    gap_score = min(gap / 0.5, 1.0)
    balance_score = 1.0 - abs(perfect_ratio - 0.5) * 2
    polarization = gap_score * balance_score
else:
    polarization = 0.0
```

- **gap**: 完全群と不完全群の平均スコアの差
- **perfect_ratio**: 完全認識できた本の割合
- **高い値**: 明確に二極化している

## 結論

✅ **質問への回答: 「本が100%認識できるものとできないもので二極化しているか」**

| モデル | 回答 |
|--------|------|
| AmazonNova | **YES** - 強く二極化 |
| Gemini | **YES** - 二極化傾向あり |
| Qwen | **NO** - 均等分布、二極化なし |
| Llama | **WEAK** - わずかな二極化 |
| Claude | **NO** - 全て失敗 |

**OCR方法によって二極化の度合いが大きく異なる**ため、アプリケーション要件に応じてモデルを選択・組み合わせることが重要です。
