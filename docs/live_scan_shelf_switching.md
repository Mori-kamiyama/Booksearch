# ライブスキャンの棚切り替え

## 現在の実装

- カメラ映像はブラウザで取得する。
- ブラウザ内のOpenCV.js/WASMが`DICT_APRILTAG_36h11`を約450ms間隔で検知する。
- 同じタグ集合を3回連続で検知したときだけ、棚切り替えイベントを確定する。
- 切り替えイベント時には、画面に新しい棚の通知と検知履歴を表示する。
- 棚の向き・象限・正確な棚割当は既存のバックエンド検知を正式な判定として残す。
- OpenCV.jsはカメラモード開始時に遅延読み込みするため、通常の検索画面の初期JSを増やさない。

## 意図

ブラウザ側は低遅延の棚切り替えトリガー、バックエンドは確定判定という役割分担にする。タグ検知が動かないブラウザでは、既存の`POST /api/tags/detect`にフォールバックする。

現在、Gemini OCRとcatalog確定は撮影終了後の既存フローであり、次の段階で棚サイクル単位のYOLO/OCR処理へ接続する。
