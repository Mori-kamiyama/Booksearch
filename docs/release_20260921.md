
通常BM25では「シベリアのバイオリン」から「バイオプラ」「オリンピック」への文字片一致があり、そのまま配信する品質には足りなかった。初期配信では同一正規化著者、分類先頭3文字、共通カテゴリのいずれかを必須にした。20冊を抜き出した確認でも、分類による広い候補は残る。書誌情報に基づく初期版であり、読者による関連性・多様性の評価は継続課題。
