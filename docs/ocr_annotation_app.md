# 背表紙OCR校正Webアプリ

既存の疑似ラベルをゼロから打ち直さず、LoRA・Gemini・学習前モデルの候補を選択または修正して、人手校正済みJSONLを作るローカルWebアプリ。

## 起動

```bash
uv run python scripts/annotation_web.py
```

ブラウザで <http://127.0.0.1:4180/> を開く。

## 操作

- `1`: LoRA候補
- `2`: Gemini候補
- `3`: 現在の疑似ラベル
- `4`: 学習前PaddleOCR-VL
- `0`: 直前に保存した文字列を貼り付け
- `Cmd/Ctrl + Enter`: 保存して次へ
- `S`: 除外
- `←` / `→`: 前後移動

保存先は `outputs/ocr_annotations/annotations.json`。画面右上の「JSONLを書き出す」で、PaddleOCR-VL/ms-swift用の確定済みデータだけをダウンロードできる。

「直前を貼る」は、最後に保存した確定文字列を現在の入力欄へコピーする。サーバーに保存済みの最新データを使うため、ページを再読み込みしても利用できる。画像固有のフラグはコピーしない。

デフォルトでは6,276件を読み込む。LoRA・Gemini比較が存在する100件は「比較結果あり」フィルターで先に確認できる。2冊入り、読めない、crop不良はフラグを付けられる。除外したデータは学習用JSONLへ出力されない。
