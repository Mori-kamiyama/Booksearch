# 検索語と読者向けジャンル（2026-09-28）

## 方針

表示ジャンルは、IT・プログラミング／デザイン・アート／建築・まちづくり／ビジネス・経済／科学・数学／工学・ものづくり／社会・歴史／哲学・心理／言語・語学／小説・文学／暮らし・趣味／学び・教育の12区分。NDCは判定の手掛かりとして内部で使い、書名・テーマでも追加する。1冊に複数ジャンルを付け、分類根拠をbook_topicsに残す。利用者による分類確認済みという意味ではない。

テーマは35ルールへ拡張。C++、C#、Java、自然言語処理、ユーザー調査、CAD、線形代数などを追加。テーマの親ジャンルは明示的に管理し、たまたま複数ジャンルに入る1冊のために「IT」のテーマ選択肢へ「英語学習」が混入することを避ける。件数0のテーマは表示しない。

旧ndc-*はlegacyとして索引とDBに残すので、保存済みURLの検索は壊さない。新しい選択肢と候補からは隠す。旧形式の索引を読む互換処理も維持する。

## 検索

book_search_termsへ書名・著者・検証済みの読み・割り当て済みテーマ/ジャンルの別名を収録。全半角・大小文字・かなを揃え、SQLの各AND語に追加照合する。件数計算・絞り込み・ページ分割の前に適用する。旧DBは従来の検索を維持する。

「Python」「パイソン」「ぱいそん」で同じ185冊、「ぱいそん＋IT＋300ページ以下」で31冊、デザイン＋UIデザインで4冊を確認。読みの未収録本・登録されていない別名を網羅する仕組みではない。

0件の場合は、ブラウザ内の蔵書/テーマ辞書から編集距離で最上位の訂正候補を選び、同じ条件で1回だけ自動再検索する。訂正後も結果がなければ「見つかりませんでした」。結果がある場合は「次の検索結果を表示しています：…」と明示し、元の入力とURLを保持する。「元の検索語で検索」はexact=1をURLに保存して自動訂正を解除する。条件・ページ送り・詳細からの戻りを維持し、API障害を0件と取り違えない。

短い語、ISBN、C++/C#を含む語、著者名の近似訂正は対象外。正しい書名・別名に一致する場合も訂正を出さない。意味ベクトル検索、自然文条件の解釈は未実装。
