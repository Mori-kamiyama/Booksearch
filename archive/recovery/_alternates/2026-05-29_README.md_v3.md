# Booksearch

本棚画像から箱を検知する YOLO データセットを作るためのリポジトリです。
AI による自動アノテーションは使わず、画像を見ながら手で矩形を付ける流れを標準にしています。

## 手動アノテーションの流れ

1. `scripts/init_yolo_dataset.py`
   `data/` の画像から YOLO 形式のデータセットを作ります。
2. `scripts/review_yolo_boxes.py`
   画像を開いて、箱の矩形を手で追加・削除します。
3. `scripts/annotation_status.py`
   進捗と付与済み box 数を確認します。

## 1. データセットを作る

```bash
uv run python scripts/init_yolo_dataset.py --dataset-dir dataset/box_detection --source-dir data
```

これで次の構成ができます。

```text
dataset/box_detection/
  dataset.yaml
  images/train/
  images/val/
  labels/train/
  labels/val/
  meta/reviewed/train/
  meta/reviewed/val/
```

## 2. 手でアノテーションする

```bash
uv run python scripts/review_yolo_boxes.py --dataset-dir dataset/box_detection --split train --only-unreviewed
uv run python scripts/review_yolo_boxes.py --dataset-dir dataset/box_detection --split val --only-unreviewed
```

操作:

- 左ドラッグ: box を追加
- 右クリック: その box を削除
- `+` / `-`: 表示を拡大 / 縮小
- `n`: 保存して次へ
- `p`: 保存して前へ
- `s`: 保存
- `c`: 全削除
- `d`: 最後の box を削除
- `r`: reviewed フラグ切り替え
- `q`: 保存して終了

`n` / `p` / `s` で保存した画像は `meta/reviewed/...` に reviewed フラグが付きます。
次回は `--only-unreviewed` を付けると未完了画像だけ開けます。

大きな画像は自動で画面内に縮小表示されます。保存されるラベルは元画像サイズ基準の YOLO 形式です。
もっと大きく表示したい場合:

```bash
uv run python scripts/review_yolo_boxes.py --dataset-dir dataset/picture_box_detection --split train --only-unreviewed --zoom 1.5
```

途中の画像から始めたい場合:

```bash
uv run python scripts/review_yolo_boxes.py --split train --start shelf_2.jpg
```

## 3. 進捗を確認する

```bash
uv run python scripts/annotation_status.py --dataset-dir dataset/box_detection
```

表示例:

```text
train images=  4 reviewed=  0 remaining=  4 labeled=  1 boxes=  1
val   images=  1 reviewed=  0 remaining=  1 labeled=  1 boxes=  1
total images=  5 reviewed=  0 remaining=  5 labeled=  2 boxes=  2
```

## 4. YOLO 学習

```bash
uv run yolo detect train data=dataset/box_detection/dataset.yaml model=yolo11n.pt epochs=100 imgsz=640
```

## 5. 箱 crop から蔵書リストを作る

学習済み YOLO モデルで箱を検出し、箱ごとの切り抜き画像を Gemini OCR に渡して
`catalog.json` を作ります。OCR では背表紙から読めるタイトルだけを抽出します。

```bash
export GEMINI_API_KEY=...
uv run python scripts/build_book_catalog.py
```

出力:

```text
outputs/book_catalog/
  catalog.json
  crops/
  previews/
```

デフォルトでは、抽出したタイトルから Google Books で書誌情報も検索します。
OCRだけ行い、書誌情報検索を止めたい場合:

```bash
uv run python scripts/build_book_catalog.py --no-lookup
```

OCR を使わず、箱検出と crop だけ確認したい場合:

```bash
uv run python scripts/build_book_catalog.py --source data --output-dir outputs/book_catalog --skip-ocr
```

## 6. 蔵書リストを検索する

```bash
uv run python scripts/search_book_catalog.py "旅をする木" --catalog outputs/book_catalog/catalog.json
uv run python scripts/search_book_catalog.py "978" --catalog outputs/book_catalog/catalog.json --field isbn
uv run python scripts/search_book_catalog.py "add_tag:box_03" --catalog outputs/book_catalog/catalog.json --field box
```

## 7. デモUI

画像をアップロードすると、箱検出、crop、Gemini OCR、ローカル図書DB検索、
Google Books由来の書影表示まで実行します。

```bash
export GEMINI_API_KEY=...
uv run python scripts/build_library_db.py
uv run python scripts/demo_web.py
```

Google Books API の書影キャッシュを少しずつ増やす場合:

```bash
export GOOGLE_BOOKS_API_KEY=...
uv run python scripts/fetch_google_book_covers.py --limit 900
```

1日の上限に余裕を残すため、デフォルトは900件です。429などの連続エラーが出た場合は自動で停止します。

ブラウザで開く:

```text
http://127.0.0.1:4174/
```

## メモ

- 最初はクラスを `box` 1つに固定しています。
- ラベルは `dataset/box_detection/labels/<split>/<画像名>.txt` に保存されます。
- 画像追加後は `scripts/init_yolo_dataset.py` をもう一度実行すると、未追加分の画像と空ラベルを作れます。
- 検出、OCR、DB照合、低品質 crop 除外の実験結果は `docs/pipeline_experiment_notes.md` にまとめています。
